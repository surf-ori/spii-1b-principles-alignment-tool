# Presentation: Open Science NL, 2 December 2026

Eight slides (about 6–7 minutes) introducing the Principles Alignment Tool, based on Nida’s talking notes. Updated 27 November 2026 for the new interface, with a QR code to the tool on the first and last slide.

- Open `index.html` in a browser, or online: https://surf-ori.github.io/spii-1b-principles-alignment-tool/docs/presentation/2026-12-02-osnl/
- Keys: ← → (or click) to browse, N shows the speaker notes, F full screen, P print (one slide per page, also to PDF).
- `#slide-3` in the address opens slide 3.
- One self-contained file (slides are 1920×1080, scaled to the window); the screenshots are the PNG files next to it (principle.png, framework.png, overview.png), the Outfit font comes from `../../../fonts/`, and the favicon from the SPII design system.
