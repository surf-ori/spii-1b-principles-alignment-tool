# Presentation: Open Science NL, 2 December 2026

Thirteen slides (about 9 minutes) introducing the Principles Alignment Tool, based on Nida’s talking notes. Updated 27 November 2026 for the new interface, with a QR code (edu.nl/axnxx, to these slides) on the first and last slide a seven-slide walk through a POSI report (the same steps as the tour in the tool, ending with saving it to Word for an NWO proposal), and one slide with two extras.

- Open `index.html` in a browser, or online: https://surf-ori.github.io/spii-1b-principles-alignment-tool/docs/presentation/2026-12-02-osnl/
- Keys: ← → (or click) to browse, N shows the speaker notes, F full screen, P print (one slide per page, also to PDF).
- `#slide-3` in the address opens slide 3.
- One self-contained file (slides are 1920×1080, scaled to the window); the screenshots are the PNG files next to it (t1–t6.png, t7-word-report.png, word.png, framework.png, overview.png), the Outfit font comes from `../../../fonts/`, and the favicon from the SPII design system.
